AudioTrim Support

Help with trimming, importing, and sharing audio.

Get help

Found a bug or have a question? Open an issue on GitHub and describe what happened. Include your iPhone model and iOS version if you can.

Common questions

How do I get audio into AudioTrim?
Tap + to import from Files, open an audio file and choose AudioTrim, or use the Share button in another app (like Voice Memos) and pick AudioTrim.

Which formats work?
MP3, M4A, and WAV import from Files. Trimmed clips are saved as M4A.

How do I make a precise cut?
Drag the yellow handles, pinch to zoom the waveform, or tap the Start or End time to type an exact time. Use the nudge buttons for tiny adjustments.

What does Snap to Silence do?
When it's on, a cut moves to the nearest quiet moment so it lands between words. Turn it off from the ⋯ menu in the editor.

Will trimming delete my original?
Only if you choose Trim Audio and confirm. Save as New keeps the original and adds the trimmed clip.

Is my audio uploaded anywhere?
No. AudioTrim has no network access. See the privacy policy.
